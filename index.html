Thời Khóa Biểu Gia Đình

Điền lịch tuần, lưu tự động trên máy này. Bấm «Sao chép link» để gửi cho cả nhà — người mở link GitHub sẽ thấy đúng bản bạn đang xem.

Chưa có thay đổi.

Host trên GitHub Pages (không có máy chủ lưu chung). Link có chứa dữ liệu lịch — ai có link đều xem được. Xóa cache trình duyệt sẽ mất bản chỉ lưu local; bản trong link vẫn mở được nếu bạn giữ URL.
